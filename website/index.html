Fraud screening for small online stores

Sentinel scores each card order on 41 behavioural signals, then allows, verifies or declines it at the lowest expected cost. In a replay of 21,596 simulated orders, fraud losses, chargeback fees and lost sales fell from $77,219 to $14,776, an 81% cut.

    The policy

    A $9 order and a $900 order with the same risk get different treatment. Sentinel declines only when turning a buyer away costs less than the fraud it stops, and asks for a code when a few seconds of friction is the cheapest answer.

    Does Sentinel touch real money?

    No. Orders, payments, verification and chargebacks are all simulated.

    How does Sentinel score real card data?

    On 284,807 real ULB transactions the scoring model reached AUPRC 0.79 against 0.75 for logistic regression, with overlapping intervals.

    Why is friendly fraud at 0%?

    It is built to look exactly like a genuine order, so no signal can catch it. It caps recall at about 95%.

    Can a merchant set Sentinel’s cost figures?

    Yes. The what-if panel re-optimises for any margin, chargeback fee or verification cost.

    When does a person review an order?

    Only when an order passes verification yet risk stays at 90% or more. That happened 0 times in test.
